# 入职合规核验机器人 / Onboarding Compliance Checker

**一句话**：把入职材料登记表逐项对照 10 条合规规则，输出缺失项与风险台账（每条带规则编号与行号，可直接催办）。
**行业**：人力资源 ｜ **分级**：普通级（S） ｜ **编号**：S-15 ｜ **版本**：v1.0 ｜ **署名**：daai

---

## 它解决什么

入职材料散在纸质袋、微信、邮箱里，HR 靠肉眼看：离职证明有没有、体检报告过期没、合同是不是**先上岗后签约**——漏一件，赔的是仲裁。本工具把这件事变成**一次跑批**：6 人的表 1 秒出结果，100 人也是秒级。

**典型收益（口径）**：把"逐份翻找 + 凭印象判断"变成"规则清单 + 行号定位"，漏件可复核、可追溯、可留痕。

## 它不解决什么

- 不核验材料**真伪**（只做身份证号格式校验）
- 不查社保、个税、司法记录
- 不生成劳动合同文本、不做电子签

## 环境要求

- **Node.js ≥ 18**（无第三方依赖、无网络调用、全程本地运行）
- Windows / macOS / Linux 均可

## 三步跑通

```powershell
# 1) 照列名准备登记表（列名照 samples\in-onboarding-6p.csv，不要改）
# 2) 出件
node tools\check-inbound.mjs --in 你的登记表.csv --out out\台账.md --ledger out\台账.csv
# 3) 自测（确认环境 OK）
node check\selfcheck.mjs
```

## 规则清单（口径）

| 规则 | 内容 | 等级 |
|---|---|---|
| R01 | 劳动合同必须已签 | 高 |
| R02 | 身份证复印件须留存 | 中 |
| R03 | 管理/技术/职能岗须留存学历证明 | 中 |
| R04 | 非应届生须有离职证明；应届生须有三方协议 | 中 |
| R05 | 体检报告须在入职前 6 个月内，且不得晚于入职日 | 中/高 |
| R06 | 银行卡信息须留存 | 低 |
| R07 | 紧急联系人须填写 | 低 |
| R08 | 合同签订日期不得晚于入职日期 | 高 |
| R09 | 身份证号 18 位且校验位正确（仅格式） | 低 |
| R10 | 不得使用未满 16 周岁；16–18 周岁须做未成年工登记 | 高/中 |

## 常见问题

- **列名能改吗？** 不能直接改，按 `templates/` 的列名对齐即可；空值按"未留存"处理。
- **能加自己的规则吗？** 能：`tools/check-inbound.mjs` 里 `RULES` 与 `checkPerson()` 两处对应加一条即可（编号沿用 Rn 规则）。
- **结果能当结论用吗？** 不能——请 HR 负责人 / 合规持证人复核后采用（见 `SKILL.md` §7）。
